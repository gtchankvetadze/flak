This repository contains a C implementation of the legendary MOS Technology 6502 8-bit processor. 

## Acknowledgements

This project was developed while studying Arlet Ottens'
[verilog-6502](https://github.com/Arlet/verilog-6502), which I use as a
reference for the CPU's datapath, control logic, and cycle-level behavior.
